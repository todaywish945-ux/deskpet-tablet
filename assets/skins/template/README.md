# 模板皮肤

一个开箱即用的皮肤骨架：**内置通用人设「阿板」**（prompts/character.md，装完就能正常聊天）、
可见的待机/说话占位图、默认头像。

- 没放动画素材时框架自动进入「贴纸占位模式」，对话、语音、情绪流程照常可跑
- 想换成自己的角色：
  - **人设**：按 `prompts/TEMPLATE-GUIDE.md` 填好后覆盖同目录 `character.md`
  - **形象**：把动画/贴纸/头像按仓库根目录 **ASSET-GUIDE.md** 放进对应位置
  - 或把本文件夹整体复制一份改 `skin.json` 的 `id`，做出多套皮肤随时切换
- 用户自装皮肤放 `%APPDATA%/deskpet-tablet/skins/<皮肤id>/`，优先级高于内置，升级框架不丢失
