# 动画素材放置说明

把叶瞬光的动画视频（当前用的是 2880×2160@60fps H.264 无损原片，背景烤在画面里）放进本目录，
然后在 `manifest.json` 里声明：

```json
{
  "idle": ["idle_01.mp4", "idle_02.mp4", "idle_03.mp4", "idle_04.mp4"],
  "talk": "01_hand_up_cheek.mp4",
  "emotions": {
    "celebrate": "03_fist_to_chest.mp4",
    "shy": "12_shy_eyes_close.mp4"
  }
}
```

## 规则

- **idle**：待机动画（必填）。可以是单个字符串或数组；待机时**单曲循环**当前段，
  **点击平板屏幕**切换到数组里的下一段继续循环。只用闭嘴安静的片段，开口说话的不要放这里。
- **talk**：说话循环片段（可选）。她说话时循环播放，说完回到待机；没提供时保持待机画面。
- **emotions**：情绪片段（可选）。回复的情绪标签命中时播放一遍，播完自动回到说话/待机；
  没映射的情绪直接沿用说话/待机画面。可用情绪名见 `src/shared/types.ts` 的 `EMOTIONS`。

## 当前映射（见 manifest.json）

celebrate/encourage→挥拳加油 03，shy→害羞掩面 12，affection→托腮 05，
moved/comfort/rest/tired→温柔闭眼笑 07，night/sleepy→闭眼 16，playful→眨眼 09，
curious/thinking→歪头 11，agree→眨眼 14，morning/thanks→微笑 15，welcome→睁眼 08。
想调整直接改 manifest.json，重启生效。

## 动作衔接一览（过渡规则）

所有层间切换统一用 **0.55 秒交叉溶解**（`src/renderer/pet/style.css` 的 opacity 过渡，想调快慢改这一处）。
唯一的例外是循环点跳转——因为两帧几乎相同，直接跳转零痕迹。

| 触发场景 | 过渡方式 | 说明 |
|---|---|---|
| 待机 → 说话（她开始回复） | 0.55s 溶解 | 说话片段已预载，切换零等待；风格按情绪选（见下） |
| 说话 → 待机（回复+语音结束） | **无缝链入收势片段**（播完说话尾巴后接同底片连续帧的收势，零跳变）→ 0.55s 溶解到待机 | 配对关系在 manifest.json 的 `settle`：talk_01→settle_01、talk_02→settle_02、talk_03→settle_03 |

收势片段的剪法：必须从源视频里**紧接对应说话片段出点**的位置剪（talk_01 出点 74.7s → settle_01 从 74.7s 起），
这样说话尾巴播完的画面与收势首帧是连续帧，衔接零跳变。播放器实现：说话结束时停止循环跳转，
让说话视频自然播到文件末尾（ended），自动链入配对收势，收势播完溶解到待机。
| 说话 → 情绪（回复带情绪标签） | 0.55s 溶解 | 情绪片段播一遍 |
| 情绪 → 说话（情绪播完还在说） | 0.55s 溶解 | 回到同一条回复的说话循环（风格与情绪一致） |
| 情绪 → 待机（情绪播完已说完） | 0.55s 溶解 | 直接溶解到待机 |
| 待机 → 待机（点击屏幕切换） | 0.55s 溶解 | 换另一段待机片段继续循环 |
| 待机/说话循环内部 | **无溶解、瞬时跳转** | 跳转发生在首尾几乎相同的两帧（loop-points.json），肉眼不可见 |

### 说话风格按情绪自动选择

- 明亮带笑（talk_02）：celebrate 庆祝、encourage 鼓励、playful 俏皮、thanks 感谢、welcome 欢迎、
  morning 早安、affection 亲近、moved 感动、agree 答应、curious 好奇、shy 害羞（反应演完后）
- 柔和慵懒（talk_03）：night 晚安、sleepy 困、tired 累、rest 劝歇、sad 低落、comfort 安慰、
  patience 耐心、reassure 没事、listen 倾听
- 标准（talk_01）：neutral 及其他
- 每条回复从待机开口时选定，回复内不换；无情绪指引时随机避开上一次用的

### 兜底保护

- 情绪片段播完事件异常时，25 秒兜底定时器强制回待机
- 播放时钟停走（管道冻结）1.5 秒自动重建播放层
- 新消息会立即打断当前播报与情绪，直接进入新一轮（打断只清音频，不插过渡，画面由新回复的说话动画直接接管）

### 闲置片段说明

- idle_02 / idle_04：烤着说话口型，待机会像在自言自语，不用
- 15_micro_smile：已按需从待机移除，保留在 morning/thanks 情绪映射
- 其余切片（01/04/10/13 等）为变体或无无缝循环点，按需可启用

## 无缝循环点（loop-points.json）

循环片段由 `scripts/loop-points.mjs` 分析生成最佳接缝：在片段开头/结尾窗口里穷举帧对，
找帧差最小的 (loopIn, loopOut)，播放器循环时在这两帧之间跳转——两帧几乎相同，肉眼无缝。
换素材后重跑一次：`node scripts/loop-points.mjs`（只生成 loop-points.json，不动视频）。
没有对应条目的循环片段自动退回「结尾交叉淡化」方式循环。

说话动画 `talk_01.mp4` 由 `scripts/find-talk-loop.mjs` 从源视频扫描选出：
要求「内部确实在开口说话（嘴部区域时间差分高）+ 首尾姿态一致（帧差≈1/255）」，
循环点为整段（loopIn=0 → loopOut=3.95），整段说话期间就这一个动作循环，无任何切换。

## 画质说明

原始素材未做任何转码（2880×2160@60fps 原样使用，画质无损）。若以后机器解码吃力，
可自行转低分辨率版本替换文件，manifest 不用改。
